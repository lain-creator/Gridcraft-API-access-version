# WordCraft 0.11.0 本地汉化与翻译修复版

> 历史说明：0.11.0-wordcraft.20261027.2 起已移除固定网站传输和自动纠正重试，改为用户配置 API。当前用法以 [local-api-assistant.md](local-api-assistant.md) 为准。

更新：2026-10-27。基于官方稳定标签 v0.11.0，提交 `e31f2f06a5f8004ceaa88f68c00b47908e321aa4`。这是本地定制版，不是官方发布。

开始功能区保留三个按钮：选区翻译为英文、整个文件翻译为英文、当前选区翻译为中文。打开文件不自动上传；点击按钮才将候选文字发到用户指定的 http://tech0.top:37002/translate_text。传输内容限当前范围的候选正文，完整双语也需发给 AI 核对；不发送文件路径、图片、公式或选区外文字。

中文夹有 PTH、NPTH、型号、单位不再直接跳过。AI 逐段检查目标语言是否完整，拟跳过项再复核；已有完整译文跳过，部分双语只补缺失含义。结果窗口提供处理原因。按真实 UTF-8 文字选区取值，保留换行作为双语判断上下文；支持反向选区、多个表格列选区、正文、页眉页脚和文本框。译文沿用选区末尾字符格式。

本地按请求 ID 配对返回文字，拒绝遗漏/重复 ID、错误方向、空白或异常响应。新增数字、公差和型号校验：拒绝新增数值和型号；没有既有目标语言正文时要求保留提取到的原数字、型号。校验失败只允许一次模型纠正；网络错误不自动重发。该校验不是全面语义证明，AI 仍可能误判、遗漏技术含义，需要核对关键内容。

官方 v0.11.0 每窗口一份文档。结果先保存到应用设置目录的 Translations 文件夹，再用新窗口打开；原窗口及翻译期间的编辑保留。可用“另存为”保存到希望的位置。Mac 路径：~/Library/Application Support/WordCraft/Translations；Windows：%APPDATA%\WordCraft\Translations。 原文和原有格式保留。任何批次失败、取消或超时均不应用部分译文。复杂排版仍需检查。

Windows 10/11 x64 ZIP 为便携包，全部解压后双击 EXE；翻译依赖系统 curl.exe 和网络。程序未做 Windows 发布者签名。本轮不再连接远程 Windows 电脑；Win64 校验包括交叉构建、PE 架构及系统 DLL 依赖检查，不能替代 Windows 实机运行验证。

保护文档、启用修订、含 VBA 文档不翻译；带域、控件、隐藏文字或已有修订的段落明确跳过，避免破坏其结构。独立段落之间的对应翻译、图片中的文字不做自动关联。

2026-10-27 选区专项复核：实际点击翻译按钮后，正向/反向选择及包含多字节字符的选区均保持不变；只提取选中的正文。Mac 的译文副本通过系统 LaunchServices 新开应用窗口，避免直接运行包内程序时出现后台实例无可见窗口的情况。
