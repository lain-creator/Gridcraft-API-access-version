# AI 智能图表与数据分析

统一数值格式（百分比、货币等）保留到辅助表；同列格式混合时使用 General，计数汇总使用普通数字。生成前请核对预览和单位。可点“放大预览”查看完整图表。

更新：2026-10-27；本地定制版 `0.12.1-api.20261027.3`。沿用第三方 API 设置，不增加另一套密钥或固定网址。

## 使用

1. 连同表头框选一个连续数据区域；无表头时取消“首行为表头”。
2. 右上角“AI 图表 / 分析”选择“AI 智能图表”或“AI 数据分析”，也可在右侧 AI 面板切换标签。
3. 可选填写目标，如“比较各客户销售额”“找异常和缺失项”。仅点击“分析并推荐图表”或“开始数据分析”时发送当前选区。
4. 图表返回最多三个经程序校验的方案及理由，选择后查看真实数值预览，可修改标题，再点“生成并插入图表”。默认插入源表，辅助数据另建 `AI图表N`；取消“插入当前表”则图表和数据一并放入新表。
5. 分析页显示本机统计和 AI 分析，可复制分析报告，不自动修改原表。

## 图表与计算

支持柱形、条形、折线、饼图、环形、散点图，1～6 个数值系列；分组支持不汇总、求和、平均、有效数值计数；排序支持原顺序、分类升序、第一数值系列升/降序。分类数字按数值排序，文本按字符串排序，不推测文本日期；文字月份的字典序不等于时间顺序。

统计、分组、排序由 Rust 引擎使用真实计算值完成，不采用 AI 自报的金额或数据点。AI 仅返回严格 JSON 方案，无法执行代码、SQL、公式或任意命令。列标识必须属于选区；模型和用户标题按普通文字存储。

饼图/环形图只允许 2～8 个完整非负类别、一个数值系列、有限正总额；散点图要求完整数值配对，不允许分组和排序。单图 2～500 个点。空白保留为空，文本数字、日期、错误值不当作 0；不能安全建图时提示原因。

生成的是原生可编辑图表，可随 XLSX 保存、重开，不是截图。图表引用辅助表中的**数值快照**，源数据变化后不会自动刷新，需要重新生成；不要删除被引用的辅助表。辅助表附来源范围、推荐理由和快照说明，不覆盖原始单元格、公式、图片或格式。图表与辅助表可一次撤销。

## 数据分析口径

本机逐列给出数值数、空白数、错误数、文本/布尔数、日期数、合计、平均、中位数、最小、最大；重复行按选区内显示值及类型比较。日期不计入普通数值合计，文本数字保持文本，公式使用当前结果；溢出的总计显示不可用。

隐藏/筛选行会包含并明确计数，合计/小计行不自动排除，选择时注意避免重复计入。AI 分析需结合这些口径核对，尤其金额、型号、不同币种和单位。没有时间列不能推断时间趋势，不证明因果，不自动预测或访问选区外资料。

## 安全和限制

- 单个矩形选区，最多32列、10000个格子、1000个非空单元格、64 KB显示文字、160 KB结构化数据。超限不悄悄截断；暂不支持合并数据区域、图片分析。
- 请求固定数据和 API 配置快照，不携带旧对话、工作簿路径或密钥；切换工作簿取消等待并清空结果。停止后不采纳返回，不自动重试付费调用。
- 插入前检查工作簿 UID、修订号和工作表；编辑/撤销/切表后要求重新生成。改变框选不把旧结果重定向到新区域。
- 工作簿结构保护禁止新建辅助表；源表受保护时可改为插入新表。图表方案先校验再预览，最终插入前再次校验。
- 所选服务商会收到选区和本机统计，并按其政策计费/处理；打开面板、切换标签和框选不会调用 API。
- 复杂轴、日期间距、标签布局和与 Excel 的完整兼容度仍受上游限制，本轮不提高上游图表就绪度估计。

## 命令与回归

引擎：`data.aiProfile`（只读）、`insert.aiChart`（校验后插入，可撤销）。UI：`ui.ai.charts`、`ui.ai.analyze`（仅打开），`ui.ai.charts.generate`、`ui.ai.analyze.run`（显式请求），`ui.ai.charts.insert`、`ui.ai.insights.status`。原有取消、清空和最小化仍可用。

测试：`engine/src/insights_tests.rs`、`ui-egui/src/ai_insights_tests.rs`，覆盖零/空白、分组、散点配对、异常 JSON、选区外列、文本注入、不可变请求、取消/切换、预览不改文档、按钮插入、一次撤销及 XLSX 重开。`ai_preview --charts` / `--analysis` 使用合成数据检查界面。测试不使用用户表格、真实密钥或付费服务；真实模型质量需配置 API 后核对。
