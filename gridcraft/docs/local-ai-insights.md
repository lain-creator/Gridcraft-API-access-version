# AI 智能图表与数据分析

统一数值格式（百分比、货币等）保留到辅助表；同列格式混合时使用 General，计数汇总使用普通数字。生成前请核对预览和单位。可点“放大预览”查看完整图表。

更新：2026-10-28；本地定制版 `0.12.1-api.20261028.1`。沿用第三方 API 设置，不增加另一套密钥或固定网址。

## 使用

1. 框选希望分析的区域。支持纵向记录，也支持日期横排、下一行放数值的横向记录，不需要手动转置。
2. 右上角“AI 对话”打开唯一对话面板，直接输入“分析这些数据并生成合适的图表”“找异常和缺失项”等；只有发送才调用 API。
3. AI 自主判断任务、表头及方向。程序提供各可用解释的本机统计，不固定把首行当作表头。回答下显示采用的方向/表头口径，可展开核对本机统计。
4. 若有适用图表，回答里显示最多三个经程序校验的方案、真实数值预览和插入按钮。可选择方案、改标题、放大预览，再点“生成并插入图表”。默认插入源表，辅助数据另建 `AI图表N`；取消“插入当前表”则图表和数据一并放入新表。
5. 在同一输入框继续追问或要求调整图表。保留对话上下文，仅最新回答的图表可预览/插入；旧回答仍保留。新请求使用当时的选区快照。
6. 单格、单行、纯文本或不适合图表时仍分析现有信息、说明结论边界或提出具体补充问题，不因空图表方案整体报错。合并/不连续区域可文字问答，不能直接生成图表。分析不自动写表。

## 图表与计算

支持柱形、条形、折线、饼图、环形、散点图，1～6 个数值系列；分组支持不汇总、求和、平均、有效数值计数；排序支持原顺序、分类升序、第一数值系列升/降序。分类数字按数值排序，文本按字符串排序，不推测文本日期；文字月份的字典序不等于时间顺序。

统计、分组、排序由 Rust 引擎使用真实计算值完成，不采用 AI 自报的金额或数据点。AI 仅返回严格 JSON 方案，无法执行代码、SQL、公式或任意命令。列标识必须属于选区；模型和用户标题按普通文字存储。

饼图/环形图只允许 2～8 个完整非负类别、一个数值系列、有限正总额；散点图要求完整数值配对，不允许分组和排序。柱形/条形图 1～500 个点，其余至少2个。空白保留为空，文本数字、日期、错误值不当作 0；不能安全建图时保留分析并提示原因。

横向布局在内存中展开记录，不修改原单元格。系列标识 `R2` 表示原表第2行，普通纵向布局仍使用 `A/B` 等列标识；每个值保留原始地址。表头、方向、引用、分组、排序均在插入前用相同快照和规则重新校验。模型返回无效图表时过滤该图表，不丢弃有效分析回答。

生成的是原生可编辑图表，可随 XLSX 保存、重开，不是截图。图表引用辅助表中的**数值快照**，源数据变化后不会自动刷新，需要重新生成；不要删除被引用的辅助表。辅助表附来源范围、推荐理由和快照说明，不覆盖原始单元格、公式、图片或格式。图表与辅助表可一次撤销。

## 数据分析口径

本机逐列给出数值数、空白数、错误数、文本/布尔数、日期数、合计、平均、中位数、最小、最大；重复行按选区内显示值及类型比较。日期不计入普通数值合计，文本数字保持文本，公式使用当前结果；溢出的总计显示不可用。

隐藏/筛选行会包含并明确计数，合计/小计行不自动排除，选择时注意避免重复计入。AI 分析需结合这些口径核对，尤其金额、型号、不同币种和单位。没有时间列不能推断时间趋势，不证明因果，不自动预测或访问选区外资料。

## 安全和限制

- 图表使用单个矩形选区，最多32个逻辑列/系列、10000个格子、1000个非空单元格、64 KB显示文字、160 KB结构化数据；横向记录不受原表32列限制，仍受总量限制。超限不悄悄截断；合并/不连续区域可文字分析，图片内容不发送。
- 请求固定数据和 API 配置快照，携带同一工作簿的有限近期对话，不携带路径或密钥；切换工作簿取消等待并清空结果。停止后不采纳返回，不自动重试付费调用。
- 插入前检查工作簿 UID、修订号和工作表；编辑/撤销/切表后要求重新生成。改变框选不把旧结果重定向到新区域。
- 工作簿结构保护禁止新建辅助表；源表受保护时可改为插入新表。图表方案先校验再预览，最终插入前再次校验。
- 所选服务商会收到选区、本机统计和同一对话上下文，并按其政策计费/处理；打开面板和框选不会调用 API。提供多个方向/表头统计会增加请求用量，真实模型判断仍需核对。
- 复杂轴、日期间距、标签布局和与 Excel 的完整兼容度仍受上游限制，本轮不提高上游图表就绪度估计。
