# GridCraft 0.12.1 本地汉化与翻译修复版

> API 定制版已用可配置的第三方 API 替换下面记录的历史固定网址。当前行为以 `local-api-assistant.md` 和仓库根目录 README 为准；以下保留为此前修复背景，不代表仍访问旧站点。

更新：2026-10-27。基于官方稳定标签 v0.12.1，提交 `f86aec12dabc744b5f75e1033f87bfe685e78481`。这是本地定制版，不是官方发布。

开始功能区保留三个按钮：选区翻译为英文、整个文件翻译为英文、当前选区翻译为中文。历史版本点击按钮才将候选文字发到原固定翻译服务（API 定制版已完全替换此服务）。传输内容限当前范围的候选正文，完整双语也需发给 AI 核对；不发送文件路径、图片、公式或选区外文字。

中文夹有 PTH、NPTH、型号、单位不再直接跳过。AI 逐段检查目标语言是否完整，拟跳过项再复核；已有完整译文跳过，部分双语只补缺失含义。结果窗口提供处理原因。保留 XLS 自动转换（需安装官方 LibreOffice）、中文文字垂直对齐及自动行高修复。

本地按请求 ID 配对返回文字，拒绝遗漏/重复 ID、错误方向、空白或异常响应。新增数字、公差和型号校验：拒绝新增数值和型号；没有既有目标语言正文时要求保留提取到的原数字、型号。校验失败只允许一次模型纠正；网络错误不自动重发。该校验不是全面语义证明，AI 仍可能误判、遗漏技术含义，需要核对关键内容。

译文作为新的未保存工作簿打开，手动另存 XLSX。 原文和原有格式保留。任何批次失败、取消或超时均不应用部分译文。复杂排版仍需检查。

Windows 10/11 x64 ZIP 为便携包，全部解压后双击 EXE；翻译依赖系统 curl.exe 和网络。程序未做 Windows 发布者签名。本轮不再连接远程 Windows 电脑；Win64 校验包括交叉构建、PE 架构及系统 DLL 依赖检查，不能替代 Windows 实机运行验证。
