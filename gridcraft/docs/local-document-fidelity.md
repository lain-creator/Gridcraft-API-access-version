# 文档字体与 XLS 兼容更新

更新：2026-10-27。定制版 0.12.1-api.20261027.2，不改变上游就绪度估计。

缺失原字体会改变字宽/行高；原分段字符串被压平；按文字墨迹中心定位使英文、数字和中文基线漂移。本轮保留原单元格对齐，按字体设计选择替代，显示替换提示，保留文件内原字体名。

Cell 保存可选 run 字体属性，缺失项继承整格。共享/内联字符串均读取，写为 inline 避免同文不同格式合并，同时保留注音元数据。未改文字的编辑保留分段，整格格式命令同步处理 run，改文本不套用旧分段，清格式清除 run 格式。

显示和自动行高共用 egui LayoutJob，采用稳定逻辑行框。字体绑定后再次拟合自动行，不缩短导入较高行、不改自定义行和多行合并区域。无 UI 字体时使用估算。列宽仍采用固定默认数字宽度，不宣称 Excel 像素等价。

桌面 `.xls` 使用隔离的本机 LibreOffice 转换，原文件不变，禁止宏/链接更新，有限超时。找不到转换器明确失败；引擎 BIFF8 值读取不是桌面默认。编辑后另存 `.xlsx`，不写回 `.xls`。

回归：`xlsx/src/tests/rich_text.rs`（共享/内联、空格、继承、同文不同字号、重开）；`engine/src/tests.rs`（编辑、整格字号/粗体、清格式/撤销、行高）；`ui-egui/src/cell_text.rs`、`grid.rs`（共享布局和多缩放）；`apps/gridcraft/src/xls_compat.rs::real_libreoffice_roundtrip_with_synthetic_xls`（真实转换、原文件不变）。原图片、剪贴板、API 测试保留，界面用无窗口 snapshot 检查。

限制：复杂图表、分页、部分上下标、替代字体仍可能不同；没有本轮 Windows 桌面实机测试或全量 Excel 对照。

修订记录：2026-10-27，新增中文替代、分段文字、实际行高与 XLS 发布说明。
