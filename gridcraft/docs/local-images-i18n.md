# GridCraft 汉化与图片修复（2026-10-27 第二次更新）

基于 v0.12.1，保留已有 XLS 转换、三个翻译按钮和取值修复。

- 补充 958 条中文界面文字（中文目录共 1382 条），覆盖次级菜单、对话框、悬浮提示、命令搜索及 Mac 菜单栏。接通原先绕过翻译表的显示入口。
- 补充 456 条函数说明及 269 个参数说明。函数名称、公式和数字格式代码保持标准形式。
- 浮动图片增加 EMF/WMF 显示和 PDF 输出；PNG/JPEG 之外增加 GIF/BMP/TIFF/WebP 解码。保留图片原始字节和 XLSX 裁剪参数。
- Mac 使用 Command+V、Windows 使用 Ctrl+V，或单击“粘贴”，可插入剪贴板图片。选中浮动图片后可复制或剪切；撤销可恢复。支持常见截图像素和复制的图片文件。
- 复制单元格时优先保留可编辑表格，不把表格附带的预览图误当作待粘贴图片。插入的图片保持比例，默认最长宽度不超过 640 像素，可拖动调整。
- 单元格内图片仍使用原有 PNG/JPEG 插入功能；本次剪贴板图片作为浮动图片插入。

实现说明：EMF/WMF 解析器改编自 WordCraft v0.11.0 的 MIT/Apache-2.0 源码，独立随源码交付；原始图片不被栅格化写回。渲染有资源上限，非所有罕见 EMF/WMF 记录都能表现；实际提供样表中的 EMF 已验证。桌面系统对话框的系统按钮语言由操作系统决定。浏览器端可编译，本次图片剪贴板功能针对 Mac/Windows 桌面。

验证与本地安装记录见交付目录。Windows 包完成交叉编译和结构检查，本轮不连接远程电脑。
