# GridCraft · 中文文字对齐与显示修复 1

更新：2026-10-27。已移植到 GridCraft 0.12.1，保留新版上游合并单元格行缓存。

修复中文及中英混排文字在单元格中偏上、顶部被裁掉的问题：用于中文的后备字体实际笔画可能超出主字体的逻辑行框。现在按字形实际绘制范围计算垂直对齐，顶部、居中、底部对齐均使用正确的范围，适用于普通单元格、合并区域及自动换行内容。字号、单元格值、公式及保存的样式不变。

“开始”功能区有两个独立的对齐按钮：上排“垂直居中”控制上下居中，下排“居中”控制左右居中。需要居中时同时设置两者。

单行横向合并区域现在参与自动行高，字号增大或换行时会调整高度；换行按整个合并区域宽度计算。打开文件时也会修正过小的自动行高，保留已经足够高的行。

本修复保留用户手动设置的行高、列宽及合并范围。若文字实际宽于单元格、旁边又有内容，仍需加宽列或开启“自动换行”；手动设置过小的行高需调高。跨多行的合并区域仍保留原有高度，不自动分配各行高度。

本机重复应用图标的原因是历史备份与测试 .app 被 macOS 索引。此次将 10 个历史副本改为已校验的 ZIP 备份并注销它们的应用注册，仅保留 /Applications/GridCraft.app。此后仅保存压缩备份；构建临时 .app 打包后移除，避免再次出现在应用列表。

原 XLS 自动转换和三个翻译按钮保留。Windows x64 便携包同步更新，运行验证情况见交付目录的“验证记录.md”。
